# StepMind

App móvil (Flutter) para crear hábitos positivos y acompañar la superación de adicciones.

## Requisitos

- Flutter 3.38+ (Dart 3.10+)
- Android SDK (la app apunta principalmente a Android)

## Comandos

```bash
flutter pub get       # instalar dependencias
flutter analyze       # análisis estático
flutter test          # tests
flutter run           # ejecutar en dispositivo/emulador
```
